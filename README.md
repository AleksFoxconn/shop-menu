# Магазин 24/7 — React меню

Відтворення ігрового UI магазину (React + Vite + SCSS + Context API).

## Запуск

```bash
npm install
npm run dev
```

Відкриється на http://localhost:5173

## Структура

```
src/
  data/products.js       — мок-дані товарів (22 позиції, 4 категорії)
  data/categories.js      — список категорій для сайдбару
  context/CartContext.jsx — стан кошика (додавання/видалення/кількість) через useState + Context
  components/
    ShopModal.jsx    — головне вікно (збирає сайдбар + грід + кошик)
    Sidebar.jsx       — категорії товарів
    SearchBar.jsx     — пошук за назвою
    ProductGrid.jsx   — сітка карток, фільтрація
    ProductCard.jsx   — картка товару + кнопка "Додати в кошик"
    CartPanel.jsx     — кошик, лічильники, баланс готівки/банку, кнопка оплати
    ProductIcon.jsx    — набір лінійних SVG-іконок товарів
    UiIcons.jsx        — дрібні службові іконки (пошук, кошик, +/-, кошик для сміття)
```

## Що вже працює

- Фільтрація товарів за категорією (сайдбар) та пошуком (живий пошук за назвою)
- Додавання товару в кошик, зміна кількості (+/-), видалення позиції
- Автоматичний перерахунок суми "До сплати"
- Баланс готівки/банку (мок-дані), кнопка оплати блокується при порожньому кошику
- Закриття вікна по кліку на "ESC ЗАКРИТИ" або клавішею Esc

## Що можна донастроїти

- Замінити фонове зображення (зараз — заглушка з Unsplash) на власний скріншот локації
- Підключити реальні дані товарів через API замість `data/products.js`
- Додати логіку самої оплати (списання з cash/bank, тости про успіх/помилку)
